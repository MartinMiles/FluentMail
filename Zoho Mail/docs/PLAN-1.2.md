# Fluent Mail 1.2 — Send delay and clipboard media

Owner requested: one Send click, a visible five-second countdown with Cancel returning to editing, clipboard images inserted directly in the rich body, and copied files attached. This supersedes the in-app second send confirmation; it does not authorize assistant-led production mail tests.

- Snapshot the message when Send is clicked. Save locally, disable edits during the countdown, and send once after five seconds. Cancel/unmount/explicit Exit cancels pending submission and preserves the draft. No server upload or send before expiry. Existing pending-send ledger and no-retry behavior remain.
- Read native clipboard media only on an explicit paste gesture/button, never poll/log the clipboard. Windows Explorer files use CF_HDROP/FileNameW; do not interpret ordinary copied text/URLs as file paths. Reject UNC paths and directories. Clipboard formats are parsed/tested with fixtures, not the owner's clipboard.
- Browser paste File objects can import bounded bytes without exposing filesystem access. Main process validates sizes, scoped handles and raster-image signatures. Regular files stay behind opaque attachment handles. Inline raster images use local data URLs in the editor/encrypted draft; remote/SVG image sources remain blocked.
- Use Tiptap Image with local base64 raster images. Preserve cursor at asynchronous paste insertion. Main process extracts/validates images, uploads with documented `isInline=true`, validates the returned `/zm/ImageSignature` URL against the account/region, and rewrites the corresponding img source. No guessed CID/private API. Reuse returned attachment descriptors as documented. The resulting external rendering is unverified until an owner-approved live test.
- Keep existing encrypted accounts/drafts and prior executable. Build 1.2.0, add offline tests for cancellation/timing, clipboard parsing/import, image sanitation and API mapping; package-smoke in --demo; update persistent context/test report and commit source.

Sources checked: [Zoho attachment upload](https://www.zoho.com/mail/help/api/post-upload-attachments.html), [send with attachments](https://www.zoho.com/mail/help/api/post-send-email-attachment.html), [Electron clipboard](https://www.electronjs.org/docs/latest/api/clipboard). The upload contract supplies isInline and an image URL; exact recipient-side rendering remains a production-validation limitation.
